Rueda Libre - Tienda y Alquiler de Bicicletas

Proyecto web desarrollado originalmente con HTML5 y CSS puro, y migrado completamente a Bootstrap para este entregable. 
El objetivo principal de esta actualización es garantizar una interfaz moderna, estandarizada y 100% adaptable (responsive) 
a cualquier dispositivo móvil, tablet o escritorio.

Cambios realizados en la migración a Bootstrap

Para esta versión del proyecto se reestructuró la maquetación y los estilos utilizando los componentes y utilidades de
Bootstrap:

-Sistema de Grid (container, row, col): Reemplazo de las estructuras de layout anteriores por el sistema de 
rejilla de 12 columnas de Bootstrap, asegurando una distribución fluida en todas las resoluciones.
-Tarjetas (card): Adaptación del catálogo de bicicletas (eléctricas, grava, plegables, infantiles, etc.)
utilizando el componente de tarjetas de Bootstrap para unificar imágenes, descripciones y precios.
-Tipografía y estilos de párrafo: Estandarización de textos, encabezados, márgenes y espaciados mediante las clases
tipográficas y de utilidad de Bootstrap.
-Formularios (form-control, form-select, form-label): Migración completa de los formularios de contacto y reserva
con estilos nativos de Bootstrap, mejorando la accesibilidad, alineación y experiencia de usuario.
-Diseño 100% Responsive: Optimización de navegación, imágenes (img-fluid) y contenedores para ofrecer una
visualización óptima en pantallas pequeñas y grandes.

Tecnologías utilizadas

-HTML5
-Bootstrap 5
-CSS3 (estilos personalizados complementarios)
